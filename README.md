Al descargar se tendrá que abrir el documento "htdocs" en el cual vendrá una carpeta con el nombre "Proyecto-Inventario" el cual estará otra carpeta, al abrir esta carpeta se podrá notar varios archivos, los cuales algunos ya vienen con su respectiva carpeta, las carpetas son los que tienen un mismo nivel al momento de programar, mientras los que no van en la raíz del programa, en este caso se utilizó Visual Studio Code, MySQL Workbench y xampp paralograr el funcionamiento del codigo.
